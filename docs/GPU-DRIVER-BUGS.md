This document records the GPU driver bugs I've encountered while developing Novacube, along with all the information I have on them (which might not be 100% accurate, since I've debugged just enough to work around them and nothing else).

| GPU                   | Device                                 | gpuinfo.org report                                    | Bug description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Workaround                                                                                                   |
|-----------------------|----------------------------------------|-------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------|
| PowerVR Rogue GE 8300 | Goodtel G2 (some trash Chinese tablet) | https://vulkan.gpuinfo.org/displayreport.php?id=40448 | Using 16-bit integers for vertex indices severely corrupts rendering results. I've seen what I can only describe as GPU memory corruption, with triangles all over the place and corrupt rasterization, but interestingly enough, only after a certain number of triangles rendered. Around 500 or 600 IIRC. Additionally, using the `mediump` qualifier for shader inputs/outputs corrupts them, but only for some of the triangles. I suspect 16-bit values get corrupted in the GPU or the driver after a certain number of them is present.                                                                                                                                                                                                                      | Avoid 16-bit vertex indices, `mediump`, and probably any other kind of 16-bit data. Use full 32-bit instead. |
| PowerVR Rouge GE 8320 | Galaxy A03s                            | https://vulkan.gpuinfo.org/displayreport.php?id=20573 | Same as above.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Same as above.                                                                                               |
| Adreno 610            | Motorola Moto G9 Play                  | https://vulkan.gpuinfo.org/displayreport.php?id=11917 | `vkCreateGraphicsPipelines()` returns `VK_ERROR_UNKNOWN` if the shaders it uses declare a variable with a struct type (containing more than one field?) and use it more than once. Validation layers stay radio silent. While debugging, the logcat revealed an error from the Adreno driver: `2026-07-12 14:01:46.195 28342-28379 AdrenoVK-0 net.novacubegame I Failed to link shaders.`, followed by one of these two depending on what modifications of the shader I'm trying: `2026-07-12 11:44:38.433 22817-22913 AdrenoVK-0 net.novacubegame I Info log: Assertion failed: LIs[0] == LI_Cur && "Unexpected live interval."`, `2026-07-12 12:57:32.060 17338-17421 AdrenoVK-0 net.novacubegame I Info log: Assertion failed: Reg && "this is not a register!"`. | Avoid declaring variables with a struct type. Store their members in scalar or vector variables instead.     |
